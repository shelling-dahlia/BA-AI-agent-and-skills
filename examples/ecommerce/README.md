# Example: E-commerce Website Classification Scenario

This example demonstrates how the BA Agent classifies a raw requirement and turns it into a traceable set of artifacts.

## Raw requirement
"Build an e-commerce website."

## Proposed interpretation
This is a high-level initiative statement, not a confirmed or fully specific requirement.

## Candidate business objective
- Enable customers to browse products and complete a purchase online.

## Candidate requirements (proposed)
- Product catalogue browsing
- Search and filtering
- Cart and checkout flow
- Account creation and login
- Order placement and confirmation
- Payment support
- Shipping and status updates
- Return or cancellation flows

## Candidate features (proposed)
- Product discovery
- Shopping cart and checkout
- Account and profile management
- Order management and fulfillment support

## Candidate epics (proposed)
- `EPIC-01`: Customer acquisition and product discovery
- `EPIC-02`: Purchase flow and checkout
- `EPIC-03`: Order management and post-purchase support

## Candidate user stories (proposed)
- `STORY-01`: As a shopper, I need to search and filter products so that I can find relevant options quickly.
- `STORY-02`: As a shopper, I need to add items to my cart so that I can purchase them.
- `STORY-03`: As a shopper, I need to complete checkout so that I can place an order.

## Candidate use cases (proposed)
- `UC-01`: Browse products
- `UC-02`: Add product to cart
- `UC-03`: Complete checkout

## Candidate acceptance criteria (proposed)
- The shopper can filter the product list by category and price.
- The cart shows total price and item quantity.
- Checkout requires valid customer information and accepted payment.

## Candidate implementation tasks (proposed)
- `TASK-01`: Design product catalog data model
- `TASK-02`: Implement search and filters
- `TASK-03`: Implement cart workflow
- `TASK-04`: Implement checkout validation

## Open questions that must be answered
- Who is the target customer?
- What products will be sold?
- Which payment and shipping methods are required at launch?
- Is the project B2C, B2B, marketplace, or single-seller model?
- What are the launch constraints and compliance rules?

## Classification note
These items are deliberately marked as proposals. They are valid candidate artifacts, not confirmed requirements, until the missing information is clarified.
