# Skill: Documentation Generation and Synchronization

## Purpose
Keep shared BA artifacts consistent without duplicating facts without purpose.

## Input
- multiple BA artifacts or project notes
- change requests or evolving decisions

## Output
- synchronized documentation set
- change log or versioned update notes
- references among artifacts

## Execution steps
1. Identify which artifacts are authoritative for each domain of information.
2. Update the canonical source of facts before derived documents.
3. Cross-check related artifacts for consistency.
4. Record version, date, and rationale for updates.

## Rules
- A fact should have a single primary home; other files can reference it.
- Versioning and change tracking should make updates visible and reviewable.

## Validation checks
- Are duplicates avoided or intentionally linked?
- Is there a clear record of what changed and why?
