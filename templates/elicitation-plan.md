# Elicitation Plan

## Purpose
Plan and track discovery work needed to reduce uncertainty.

## Recommended fields
- `ID`
- `Topic`
- `Purpose`
- `Stakeholders`
- `Questions`
- `Evidence expected`
- `Priority`
- `Status`
- `Owner`
- `Decision required`

## Status conventions
- `Planned`
- `In progress`
- `Completed`
- `Blocked`
