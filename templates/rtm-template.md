# Requirements Traceability Matrix (RTM)

## Purpose
Link objectives, requirements, backlog items, implementation tasks, and validation evidence.

## Recommended fields
- `Objective ID`
- `Requirement ID`
- `Feature ID`
- `Epic ID`
- `Story ID`
- `Use case ID`
- `Task ID`
- `Acceptance criteria ID`
- `Validation evidence`
- `Status`
