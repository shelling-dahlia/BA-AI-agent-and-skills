# Naming Conventions and Metadata

## Naming conventions
- Use concise, action-oriented titles.
- Prefer role-based statements for stories and goal-based names for use cases.
- Use IDs such as `OBJ-01`, `FEAT-01`, `EPIC-01`, `STORY-01`, `UC-01`, `TASK-01`, `AC-01`.

## Metadata conventions
- `ID`
- `Name`
- `Type`
- `Status`
- `Owner`
- `Source`
- `Parent`
- `Priority`
- `Date`
- `Links`

## Status conventions
- `Proposed`
- `Clarified`
- `Ready`
- `Accepted`
- `Blocked`
- `Rejected`
- `Done`
